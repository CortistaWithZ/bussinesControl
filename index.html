Condiciones comerciales por default

Nueva solicitud de cotización

Registra la solicitud del cliente. Puedes agregar varios números de parte.

Nuevo cliente

Si la empresa ya existe pero es un contacto nuevo, captura la misma empresa: se generará un ID nuevo para ese contacto.

Nuevo proveedor

Catálogo de proveedores para tener a la mano quién nos vende qué.

Cancelar solicitud

Esta acción marca el folio como cancelado. Escribe la razón.

Agregar item a la CR

Solo disponible antes de recibir la Orden de Compra del cliente.

Editar datos iniciales del renglón

Corrige descripción, número de parte, tiempo de entrega, link o notas. Los costos se editan directo en la CR.

Nuevo gasto

El IVA se calcula solo a partir del total (desglosado), a menos que lo desactives.

Nueva acción pendiente

La fecha se registra automáticamente con el día de hoy.

Nueva inyección de capital

Dinero que entra al negocio y no viene de una CR pagada (ej. aportación de socio).

Generar Orden de Compra (PO)

Elige el proveedor y los renglones que cubre esta compra. Se genera un PDF y se guarda en OneDrive.
